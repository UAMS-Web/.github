# UAMS-Web/.github

Organization-wide default files for the UAMS-Web repositories on GitHub.

GitHub applies a community health file here (such as `SECURITY.md`) to every repository in the organization that has no file of that type of its own. A repository's own copy always takes precedence. These defaults do not appear in a repository's files, history, clones or downloads.

See [About default community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file).
