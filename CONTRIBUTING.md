# Contributing

Thank you for helping with this project. This is the default guide for UAMS-Web repositories that do not have a `CONTRIBUTING.md` of their own. If the repository has one, that file applies instead.

## Before you start

- Read the repository's `README.md` and, if it has one, `AGENTS.md`. They describe how to set the project up, how to run its checks, and which branch your work starts from and merges into. Branch flows differ between repositories, so follow the repository's own.
- Search the open issues and pull requests before you file or start something new, so the work is not duplicated.
- For anything larger than a small fix, open or comment on an issue first so the approach can be agreed before you build it.

## Reporting a problem or asking for a change

Open an issue. Say what you expected, what happened instead, and the steps to reproduce it. For a change request, say what you need and why.

Do not report security vulnerabilities in public issues. Follow the [security policy](SECURITY.md) instead.

## Making a change

1. Branch from the branch the repository's README or `AGENTS.md` names.
2. Keep the change focused on one issue. Unrelated fixes belong in their own pull request.
3. Run the repository's checks before you push, and add or update tests for the behavior you changed.
4. Write commit messages and the pull request title in the imperative, verb first, with no trailing period (for example, "Add a default contributing guide").
5. Open a pull request against the branch the repository names, using the pull request template. Link the issue it resolves with a closing keyword, repeated for each issue: `Closes #1, Closes #2.` A comma-separated list links only the first.
6. Do not add an attribution footer or a session link to the pull request description.
7. Mark the pull request ready once every check on its latest commit passes. Respond to review by pushing further commits to the same branch.

## Questions

Ask on the relevant issue or pull request, or contact the repository's maintainers.
