# UAMS-Web

The web team at the [University of Arkansas for Medical Sciences](https://uams.edu) (UAMS) publishes the code behind UAMS websites here, in the open.

## What you will find here

- **The UAMS website:** the Statamic application and the add-ons built for it, prefixed `aether-`.
- **WordPress themes and plugins:** the themes and plugins that run uams.edu, uamshealth.com and related sites.
- **Shared tooling:** reusable workflows and starter templates for new add-ons and plugins.

## Security

Please do not report a vulnerability in a public issue. Use the repository's **Security** tab and choose **Report a vulnerability**. See our [security policy](https://github.com/UAMS-Web/.github/blob/main/SECURITY.md).

## Accessibility

UAMS is committed to accessible digital content. See our [accessibility statement](https://github.com/UAMS-Web/.github/blob/main/ACCESSIBILITY.md) to learn how to report a barrier.
